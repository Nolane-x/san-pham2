# Nolane Studio v0.1.0

First public Windows build of the clean Nolane Studio architecture.

Highlights:

- completely new product identity and authored desktop UI;
- deterministic local script-to-scene planning;
- local SQLite project and media library;
- Scenes / Canvas / Inspector / Timeline studio workspace;
- image/video import and low-memory FFmpeg export;
- provider-based AI/TTS configuration without mandatory local models;
- no paywall, license gate, mandatory login or mandatory telemetry in creator/export paths;
- portable Windows EXE, portable ZIP and per-user installer;
- bundled FFmpeg runtime for supported export flow.

The v0.1 release does not yet claim complete parity for every advanced drawing/object animation, multi-track trimming/cutting, generated-image or voice-authoring workflow. Those remain explicit subsequent milestones.
